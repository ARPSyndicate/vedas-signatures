# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems in this repository, such as:

- a weakness in the validation scripts or GitHub workflows (e.g. a way for a pull request to run code with write access),
- a Nuclei template in this repository that is destructive or harmful to scanned targets,
- secrets or sensitive data accidentally committed in signatures, pcaps or examples.

Report it privately through [GitHub Security Advisories](https://github.com/ARPSyndicate/vedas-signatures/security/advisories/new). We aim to acknowledge reports within 5 business days.

## Out of scope

- **Detection quality** (false positives/negatives) is not a security issue. Use the [issue forms](https://github.com/ARPSyndicate/vedas-signatures/issues/new/choose).
- **Vulnerabilities in third-party products** covered by a signature. Report those to the vendor. To request coverage, open a signature request.
